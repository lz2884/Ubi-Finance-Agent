# 二、准备 Demo 数据

## 数据文件

位于 `source_data/`：

- `01_fee_revenue.xlsx`：销售/管理费收入实际数据
- `02_cost_expense.xlsx`：销售成本、期间费用及分摊明细
- `03_budget.xlsx`：收入、成本和费用预算
- `04_product_master.xlsx`：产品主数据
- `05_customer_master.xlsx`：客户主数据
- `06_org_calendar_rules.xlsx`：组织、财务日历、映射及汇率规则
- `07_gl_control.xlsx`：独立总账控制数与核对数据

## 说明材料

位于 `documentation/`：

- `data_dictionary.xlsx`：文件、Sheet、字段、类型、主键、期间、单位及口径
- `relationship_map.xlsx`：表间关联关系、关联字段和基数
- `material_tracker.xlsx`：材料状态、版本、哈希、责任人与后续事项

这些文件保持原始名称，以维持数据字典、黄金结果和追踪表之间的引用一致性。
